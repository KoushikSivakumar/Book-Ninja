# BOOK NINJA 📚

A modern, elegant bookstore e-commerce web application.

## Overview

Book Ninja is a complete e-commerce platform for a bookstore, designed with a clean, editorial aesthetic. It allows users to browse, search, and purchase books, manage their cart and wishlist, and review books. The application includes full user authentication, order management, and an admin dashboard for managing inventory.

## Features

### User Features
- Browse books by category
- Search for books by title, author, or category
- Sort books by featured, price, rating, or newest
- View detailed book information
- Add books to shopping cart
- Modify cart quantities
- Remove books from cart
- Create an account
- Log in / Log out
- Add books to wishlist
- Remove books from wishlist
- Checkout (Cash on Delivery or Demo Card Payment)
- View order confirmation
- View order history
- Read and submit reviews

### Admin Features
- Dashboard with site statistics
- Create new books
- Edit existing books
- Delete books
- Update book stock
- Update book prices

## Tech Stack

**Frontend:**
- HTML5
- CSS3
- Bootstrap 5 (for layout utilities)
- Vanilla JavaScript

**Backend:**
- Python
- Flask
- Jinja2
- Flask-SQLAlchemy
- Flask-Login
- Werkzeug

**Database:**
- SQLite

## Architecture

The application follows a traditional server-rendered MVC architecture:

- **Models**: Define database schemas using SQLAlchemy
- **Views**: Jinja templates rendered server-side
- **Controllers**: Flask routes handle requests and responses
